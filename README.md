---

## 🚀 Quick Setup Guide

### 1. Prerequisites
- **Python**: 3.10 or higher
- **SQL Server**: AdventureWorks2019 running locally or in Docker
- **ODBC Driver for SQL Server**:
  - **macOS**: `brew install unixodbc msodbcsql18`
  - **Windows**: Download and install [Microsoft ODBC Driver 18 for SQL Server (x64)](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server).

---

### 2. Virtual Environment & Dependencies

#### macOS / Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

#### Windows (PowerShell)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

---

### 3. Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env     # Mac/Linux
copy .env.example .env   # Windows
```

Edit `.env` to match your SQL Server connection:
- Set `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`.
- Confirm `DB_DRIVER`:
  - Default for Mac / Windows: `ODBC Driver 18 for SQL Server`
  - If using Driver 17: `ODBC Driver 17 for SQL Server`

---

### 4. Database Setup & Initial Seed
Run SQLite migrations (for Authentication, RBAC, and Application Logs):
```bash
python manage.py migrate
```

Seed the default roles and demo accounts:
```bash
python manage.py setup_roles
```

Default credentials generated by seed script:
| Role | Username | Password | Access Scope |
| :--- | :--- | :--- | :--- |
| **Administrator** | `admin` | `Admin123!` | Full Admin & Governance |
| **Manager** | `manager` | `Manager123!` | All 4 Modules + Edit/Delete Presets |
| **Supervisor** | `supervisor` | `Supervisor123!` | Sales & Customer Modules |
| **Employee** | `employee` | `Employee123!` | View-Only Assigned Reports |

---

### 5. Run Development Server
```bash
python manage.py runserver
```
Visit: [http://127.0.0.1:8000](http://127.0.0.1:8000)
